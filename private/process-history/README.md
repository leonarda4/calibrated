# Calibrated: process, decisions and supplied screenshots

Publication note (5 November 2026): the user explicitly approved including this
process-history directory in Git. Its conversations, images and documentation
snapshots retain the export cutoff described below; this is not a refreshed
transcript of subsequent work. Other private scans and calibration captures
remain excluded. Historical statements about keeping this archive local
describe the policy at export time.

The project developed from a Gaussian-splat viewer into a physically walked, calibrated hallway installation, then into a sequence that deliberately changes the visible environment around the participant. Hardware/runtime troubleshooting, repeated calibration revisions and screenshot-based placement corrections shaped the work as much as the initial narrative.

This account covers the locally recoverable project history from **29 October to 5 November 2026**, exported at **2026-11-05T11:08:59.327Z**. Dates in the timeline are Zurich dates; transcript timestamps are UTC. This is an archival account of recorded requests and outcomes, not a new verification of the current application.

Start with the [searchable picture gallery](gallery.html), [pictures with original explanations](IMAGES.md), [conversation inventory](CONVERSATIONS.md), or [chronological user requests](USER_REQUESTS.md). The [contact sheet](contact-sheet.png) provides a quick visual overview.

The separately supplied participant recordings are in [videos/](videos/README.md).
They were added after this transcript export; Sam's copy removes the long blank
tail while retaining the ending audio. Video files use Git LFS.

## What the pictures document

The 24 unique images show startup/session errors, unwanted headset captions, movement-area questions, manually supplied landmarks, box positioning/orientation/ground contact, reversed-wall alignment, lighting controls, annotated floor-hole/cutout geometry, and the overly clean collapse boundary. Images 12, 19, 22 and 23 contain drawn placement annotations; image 24 motivates the organic-destruction revision. These observations come from inspecting the [contact sheet](contact-sheet.png); original full-resolution images and the messages that explain them are in [IMAGES.md](IMAGES.md).

All original decoded image bytes are retained under images/ and deduplicated by SHA-256. The 79 attachment occurrences include repeated or inherited copies in delegated threads, so they do not represent 79 different screenshots. The gallery includes every recovered user-role image, including images whose accompanying message was empty. Generated test screenshots are excluded from this collection.

## Coverage and limits

- **62 threads:** 60 Codex and two OpenCode conversations; 22 root/user threads and 40 delegated-agent threads. They contain **2,891 stored user-facing messages**, with a chronological index of 267 user entries (requests, question replies and image-only messages). Some requests repeat across the OpenCode fork.
- **24 unique images; 79 occurrences:** all decoded successfully, with no unresolved image references or JSON parse failures in the selected conversation records.
- **Memory:** the local Codex memory table contains zero generated memory entries. Durable project memory is instead present in ai/strategy.md and the design/validation documents, copied into sources/ for this snapshot.
- **Fullness:** the transcripts contain stored user/assistant message bodies and supplied pictures. They omit system/developer prompts, internal reasoning, tools and automatic permission-review threads. The inventory identifies original local event-stream paths, so these readable exports are not byte-for-byte raw session backups. Compacted or deleted content cannot be reconstructed from absent records.
- **Other providers:** the inspected Copilot session database contains no project conversations. No cloud-only history or other machine's records were accessed. This is all recovered material from the identified local stores, not a guarantee of every conversation ever held.
- **Active work:** other project conversations were still progressing during export. The latest boundary-warning request and organic-collapse revision must be treated as requested/in progress unless their own subsequent results establish completion. The sit/classroom prompt task was also active in the captured strategy. Earlier software-check results in the log are historical evidence; this archival task did not rerun the application suites or perform any headset test.
- **Preservation:** sources/ holds exact documentation snapshots; their original relative links retain repository-relative meaning. Credential-shaped strings in exported transcript text are redacted. Original session stores and source images are unchanged. This directory is now the explicitly approved exception to the repository's private-data ignore rule.

See [inventory.json](inventory.json) for source paths, session/message counts, image hashes and every image-to-message reference; [verification.json](verification.json) records the archive checks. The browser used for gallery verification was closed and did not start a real XR session.
