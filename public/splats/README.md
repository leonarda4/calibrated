# Splat assets

Private Gaussian-splat scans of the hallway live **here only on the local
machine** and are excluded from Git by `.gitignore` (`*.ply` and friends).

Expected file for the current viewer build: `hallway.ply`
(INRIA-style 3DGS export, ~266k splats).

Deliberately public synthetic fixtures belong in `tests/fixtures/synthetic/`
instead, which is tracked.
